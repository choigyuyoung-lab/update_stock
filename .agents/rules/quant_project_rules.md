# 🤖 [K-올라운드 마스터] 퀀트 주식 프로젝트 AI 개발 규칙

## 🚨 핵심 원칙 (Critical Rules)
1. **자동 Git 커밋/푸시 금지**:
   - AI는 어떠한 경우에도 `git commit`이나 `git push`를 자동으로 실행하지 않습니다. 로컬 파일 수정 및 검증만 진행합니다.
2. **노션 스키마 방어 로직**:
   - 노션 속성 수정/추가 시 반드시 `if field in props`로 열 존재 여부를 확인해야 합니다.
3. **5대 퀀트 팩터 표준 공식**:
   - `200일선`: 최근 200영업일 종가 평균 (`Close.rolling(200).mean()`)
   - `추세`: 현재가 >= 200일선 ➡️ `🟢 상승추세` / 미만 ➡️ `🔴 하락추세`
   - `12M 모멘텀`: `(현재가 - 1년전가격) / 1년전가격`
   - `52주 낙폭`: `(현재가 - 52주최고가) / 52주최고가`
   - `60일 변동성`: `returns_60.std() * np.sqrt(252)`
4. **데이터 소스 규칙**:
   - 국내 종목 및 7대 자산 1년 시계열: `FinanceDataReader` 사용
   - 해외 종목 1년 시계열: `yfinance (period='1y')` 사용
   - 투자의견 API(`HHDFS76700100`)는 호출하지 않음 (제거됨)
5. **독립 워크플로 유지**:
   - `*_price_update.yml`, `*_finance_update.yml`, `generate_report.yml`의 독립적 분리 유지.
